# [wabi] v16 — frontend separado

Esta carpeta es la versión organizada para GitHub Pages / preparación de backend.

- `index.html` mantiene el orden original de carga.
- `assets/css/`: 28 bloques CSS extraídos en el mismo orden del HTML autocontenido.
- `assets/js/`: 16 bloques JS extraídos en el mismo orden del HTML autocontenido.
- Los SVG de interfaz y los videos cortos del post-onboarding siguen embebidos dentro de sus CSS/JS correspondientes para mantener el paquete compacto y evitar volver a superar el límite de archivos del uploader web de GitHub.

## GitHub Pages

1. Descomprime el ZIP.
2. Sube **el contenido** de esta carpeta al repositorio (no el ZIP).
3. `index.html` debe quedar en la raíz del repositorio o de la rama/carpeta publicada.
4. Conserva `assets/` junto a `index.html`; no cambies sus rutas.

El HTML autocontenido entregado aparte es el indicado para abrir directamente desde Descargas.
