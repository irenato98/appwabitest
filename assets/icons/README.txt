wabi — SVG UI icons complete set (v2)

This package contains the Font Awesome Free icon variants actually referenced by wabi v11, including both SOLID and REGULAR variants where the UI uses both styles.

Folders:
- solid/
- regular/
- brands/

All SVG paths use fill="currentColor". This means UI icons inherit their CSS `color`, so the same SVG file can work in light and dark themes without separate assets.

Important:
- Brand marks (Google/Apple) are included only because the current prototype references them. Treat provider/company logos separately from neutral UI icons when finalizing brand assets.
- Microsoft Outlook and Notion in the current prototype are custom inline SVG marks rather than Font Awesome icon files, so they are not counted as missing UI symbols here.
